# Запуск разработки в Claude Code

## Подготовка (один раз)

1. Распакуйте архив в новую папку, например `C:\Projects\english-trainer`.
2. В приложении Claude откройте вкладку **Code** и выберите эту папку как папку проекта.
3. В строке под полем ввода первым стоит селектор окружения: выберите **Local**. Окружение Cloud не подходит: там нет вашей видеокарты и микрофона.
4. Если приложение спросит, доверяете ли вы папке, подтвердите. Правила разрешений из `.claude/settings.json` применяются только к доверенной папке.
5. В той же строке откройте селектор режима и выберите **Auto**. Пункт появляется, только когда режим доступен; если его нет, выберите **Accept edits**. Тогда правки файлов и команды из списка разрешений идут без вопросов, а на остальные команды Claude Code спросит.
6. В той же строке справа выберите модель: **Opus 5.5**. Перед этапом 3 переключите её там же на **Fable 5.2**, после этапа верните Opus. Модель можно менять посреди сессии.
7. Пройдите раздел «До старта» в `docs/HUMAN_TASKS.md`.

Режим **Bypass permissions** включать не нужно: документация Claude Code рекомендует его только для изолированных контейнеров и виртуальных машин.

Сессия Local выполняется на вашем ноутбуке: подключите питание и отключите переход в сон на время работы. Расположение элементов сверено с [документацией вкладки Code](https://code.claude.com/docs/en/desktop) на 10 ноября 2026 года; если интерфейс изменился, ориентируйтесь на названия, а не на место.

## Стартовый промпт

Скопируйте целиком в первое сообщение сессии:

```text
Прочитай CLAUDE.md, затем docs/design.md, docs/PLAN.md, docs/protocol.md, docs/testing.md и docs/HUMAN_TASKS.md.

Задача: реализовать приложение по плану, этап за этапом, начиная с этапа 0. Работай автономно по правилам CLAUDE.md:
- решения внутри этапа принимай сам и записывай в docs/PROGRESS.md;
- пункт закрыт только после прошедшей проверки; этап закрыт после scripts/check_stage.ps1 <N> с кодом 0 и отчёта в docs/reports/;
- после закрытия этапа сразу переходи к следующему, пока не закрыт этап 4 или пока не останется только работа, заблокированная вопросами ко мне;
- вопросы ко мне записывай в docs/HUMAN_TASKS.md и задавай одним сообщением в конце этапа.

Версии пакетов, флаги и параметры API сверяй с официальной документацией перед использованием. Ключ API у меня не проси: я введу его сам в окне приложения, когда оно появится.

В конце каждого этапа пришли короткую сводку: что сделано, замеры против целей, что не получилось, что нужно от меня.
```

## Промпт продолжения

Для новой сессии или после паузы из-за лимитов:

```text
Продолжай работу по docs/PROGRESS.md с первого незакрытого пункта. Правила прежние: CLAUDE.md.
```

## Промпт после ваших действий

Когда вы выполнили пункты из `docs/HUMAN_TASKS.md` (ввели ключ, дали доступ к микрофону, ответили на вопросы):

```text
Я выполнил пункты из docs/HUMAN_TASKS.md, отметил их и ответил на вопросы в «Очереди вопросов». Учти ответы, запусти отложенные живые проверки и продолжай по плану.
```

## Что вы получите в конце

- Приложение, которое запускается ярлыком «Тренажёр».
- Отчёты по этапам в `docs/reports/` с замерами против целей.
- `README.md` с установкой, запуском, обновлением и резервной копией.
- Список известных ограничений в `docs/reports/final.md`.
