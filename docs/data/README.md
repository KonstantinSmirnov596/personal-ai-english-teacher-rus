# Исходные данные

Первая версия данных. При реализации файлы копируются в пакет приложения (`trainer/data/`) и дальше правятся там; тесты читают рабочие копии.

| Файл | Что внутри | Кто использует |
| --- | --- | --- |
| `scenarios.json` | Шесть встроенных сценариев: роль, обстановка, цели, первые реплики | Промпт собеседника, экран «Разговор» |
| `patterns.json` | Ключи повторяющихся ошибок с названием, подсказкой и строкой для «фокуса практики» | Корректор, итоги, счётчики ошибок |
| `l1_ru_catalog.json` | Типичные ошибки произношения русскоязычных с советами и минимальными парами; американские допуски | Оценка произношения, тесты этапа 3 |
| `reading_phrases.json` | 26 фраз для режима «Чтение» с целевыми звуками; 20 слов для сверки символов | Экран «Чтение», пункт 0.7, тесты этапа 3 |
| `corrector_eval.jsonl` | 36 реплик с ожидаемым результатом корректора | Набор `live`, см. `docs/testing.md` |

## Формат `corrector_eval.jsonl`

Одна строка — один JSON-объект:

| Поле | Смысл |
| --- | --- |
| `learner_said`, `tutor_said`, `level`, `asr_unsure` | Вход корректора |
| `expect` | Допустимые ключи `pattern`. Пустой список: правок быть не должно. Непустой: хотя бы одна правка имеет ключ из списка |
| `forbid_quote` | Слова, которые не должны попасть ни в один `quote` |
| `note` | Пояснение к случаю |

## Что проверить при переносе

- Символы фонем в `l1_ru_catalog.json` записаны в обычной МФА. Их нужно привести к словарю фонемной модели и к выводу espeak-ng `en-us`; таблица соответствия — результат пункта 0.7.
- Советы в каталоге и подсказки в `patterns.json` — тексты интерфейса. Их можно уточнять, но они остаются на русском и не уходят в синтез речи.
- Набор для корректора небольшой и составлен вручную. Он ловит грубые провалы промпта, но не измеряет качество на живой речи.
