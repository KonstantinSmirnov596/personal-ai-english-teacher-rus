# Что может сделать только владелец

Claude Code обращается к владельцу только по этому списку. Новые вопросы он дописывает в раздел «Очередь вопросов» и задаёт одним сообщением в конце этапа.

## До старта

- [ ] Установлены Git для Windows и свежий драйвер NVIDIA: команда `nvidia-smi` в терминале показывает RTX 5060.
- [ ] Свободно не меньше 15 ГБ на диске: окружение, модели, кэш.
- [ ] Папка проекта открыта во вкладке Code в окружении **Local**; если приложение спросило о доверии папке, оно подтверждено.

## Этап 0

- [ ] Подтвердить установку программ, если установщик попросит права администратора (возможны Python 3.12, espeak-ng).

## Этап 1

- [ ] Создать у провайдера отдельный ключ API для этого приложения и задать ему лимит расходов.
- [ ] Вставить ключ в окне «API-подключения» самого приложения. В чат Claude Code ключ не отправлять.
- [ ] Один раз разрешить доступ к микрофону в окне приложения.
- [ ] Провести живой разговор на 10 минут и записать впечатления: задержка, голос, уместность правок.

## Этап 2

- [ ] Проверить авто-режим на своей речи: подобрать допустимую паузу, при которой реплики не обрываются.
- [ ] Выбрать голос собеседника и скорость речи.

## Этап 3

- [ ] Прочитать 10 фраз в режиме «Чтение» и отметить кнопкой «Это было верно» ложные срабатывания: так калибруются пороги под ваш голос и микрофон.
- [ ] Сравнить оценку с включённым и выключенным шумоподавлением, если Claude Code попросит записи.

## Этап 4

- [ ] Запустить приложение с ярлыка после перезагрузки компьютера и убедиться, что оно стартует без терминала.
