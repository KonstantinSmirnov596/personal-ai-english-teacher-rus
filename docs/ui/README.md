# Макеты и оформление

Четыре статичных файла показывают целевой вид экранов. Это образцы вёрстки, а не код приложения: стили в них записаны прямо в атрибутах, данные вписаны вручную, скриптов нет. Макеты собраны без просмотра в браузере; при переносе сверяй результат глазами через Playwright-скриншот и исправляй расхождения в пользу описания ниже.

| Файл | Экран |
| --- | --- |
| `main.html` | Разговор: лента, пометки, карточка правок, нижняя панель |
| `connections.html` | Настройки → API-подключения |
| `reading.html` | Чтение: фраза, разбор слова, статистика по звукам |
| `summary.html` | Итоги сессии |

Макеты подключают шрифты с Google Fonts. В приложении это запрещено: файлы Inter и JetBrains Mono (лицензия OFL) кладутся в `web/fonts/` при установке, подключаются через `@font-face`.

## Токены

Заведи их как CSS-переменные в `web/css/tokens.css` и не используй цвета вне этого списка.

| Переменная | Значение | Где |
| --- | --- | --- |
| `--ground` | `#F5F6F6` | Фон окна |
| `--surface` | `#FFFFFF` | Шапка, карточки, нижняя панель |
| `--surface-2` | `#ECEFF0` | Активная вкладка, фон второстепенных кнопок |
| `--ink` | `#15181A` | Основной текст |
| `--ink-2` | `#3D4449` | Текст пояснений в карточках |
| `--muted` | `#5A6166` | Подписи, неактивные вкладки, состояние |
| `--faint` | `#8A9196` | Волна в покое, пунктирные рамки |
| `--line` | `#DFE2E3` | Границы |
| `--line-strong` | `#C9CED1` | Границы полей ввода |
| `--accent` | `#2F54C8` | Запись, активное подключение, исправления, основная кнопка |
| `--accent-hover` | `#1E3A94` | Наведение на ссылку и основную кнопку |
| `--accent-soft` | `#F0F3FB` | Фон блока «Главный вывод» |
| `--pron` | `#8F3F06` | Текст и подчёркивание пометок произношения |
| `--pron-soft` | `#FBE3CC` | Заливка слова с ошибкой произношения |

Типографика: Inter 400, 500, 600 для интерфейса; JetBrains Mono 400, 500 для адресов, моделей, ключей и транскрипции. Базовый размер 15 px, межстрочный интервал 1,5. Подписи 13 px, мелкие метки 12 px, заголовки экранов 22–26 px. Скругления: 8 px у кнопок и полей, 12 px у карточек. Ширина ленты до 760 px.

Тема одна, светлая. Тёмная тема в первую версию не входит.

## Пометки в тексте

Вид пометки различается формой, а не только цветом.

| Что | Вид | Действие |
| --- | --- | --- |
| Грамматика и лексика | Синее подчёркивание 2 px | Клик открывает карточку правок на этой правке |
| Произношение: ошибка | Оранжевая заливка `--pron-soft`, текст `--pron` | Клик открывает разбор слова |
| Произношение: неточно | Оранжевое пунктирное подчёркивание | То же |
| Верно | Без пометки | — |

Каждая пометка — кнопка или элемент с `role="button"`, доступный с клавиатуры, с `aria-label` на русском.

## Нижняя панель

Панель закреплена внизу окна на всех экранах, где есть микрофон.

- **Волна.** 48 вертикальных столбиков. Каждый столбик — среднеквадратичный уровень сигнала за окно около 50 мс; новые значения приходят справа, старые уходят влево. Высота столбика от 2 px в тишине до полной высоты полосы. Рисуется на `canvas` или SVG по `requestAnimationFrame`, данные берутся из `AnalyserNode`.
- **Цвет волны.** Микрофон открыт, записи нет — `--faint`. Идёт запись — `--accent`. Говорит собеседник — `--muted`, источник сигнала — выход синтеза.
- **Микрофон молчит.** Если 5 с подряд уровень ниже порога шума, над волной появляется подсказка «Сигнала нет — проверьте микрофон в настройках».
- **Состояние.** Текст над волной: «Микрофон готов», «Слушаю», «Распознаю», «Думаю», «Говорит собеседник». Во время записи рядом идёт таймер.
- **Кнопка микрофона.** Дублирует Пробел. В записи становится синей.
- **Переключатели.** «Ручной / Авто» и режим правок.

Атрибуты для тестов (`data-state`, `data-level`, `data-source`, `data-testid`) перечислены в `docs/testing.md`.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| Пробел | Начать запись; во время записи — отправить; во время ответа — перебить и начать запись |
| Esc | Отменить запись; закрыть карточку или диалог |

Пробел не перехватывается, когда фокус в поле ввода. Другие сочетания клавиш не вводятся, пока не проверено, что окно Edge в режиме приложения не перехватывает их само.

## Первый запуск и пустые состояния

Макеты показывают рабочие состояния. Остальное строится в том же стиле:

- **Нет подключения.** Экран «Разговор» показывает одну кнопку «Добавить API-подключение» и строку пояснения.
- **До начала сессии.** Выбор сценария и кнопка «Начать разговор». По нажатию создаётся `AudioContext` и запрашивается микрофон.
- **Нет доступа к микрофону.** Пояснение, как разрешить доступ, и кнопка «Проверить снова».
- **Ошибка подключения.** Блок в ленте с текстом ошибки и кнопками «Повторить» и «Переключить на…».
- **Загрузка моделей при старте.** Строка состояния в панели: «Загружаю модели…»; кнопка микрофона неактивна.

## Доступность

- Все действия доступны с клавиатуры, фокус виден.
- Контраст текста к фону не ниже 4,5 : 1 для основного и вторичного текста.
- У реплик атрибут `lang="en"`, у правок и подсказок `lang="ru"`.
- При системной настройке «уменьшить движение» волна обновляется без сглаживания, остальные анимации отключаются.
