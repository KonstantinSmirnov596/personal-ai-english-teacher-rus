## Решения

Формат: дата, пункт плана, что выбрано, почему. Сюда же попадают отклонения от `docs/design.md` и изменённые критерии.

| Дата | Пункт | Решение | Причина |
| --- | --- | --- | --- |
| 2026-11-11 | 0.1 | uv 0.13.7 ставится в `.tools\uv` (venv внутри проекта), окружение приложения — `.venv` через `uv sync --locked` | uv без прав администратора и без глобальных установок вне папки проекта |
| 2026-11-11 | 0.1 | Приёмка этапа: `scripts/check_stage.py` (вызывается из `check_stage.ps1`) читает JUnit XML и требует, чтобы перечисленные тесты прошли, а не были пропущены | Код выхода pytest не отличает «тест не найден» от «прошёл» |
| 2026-11-11 | 0.2 | torch 2.11.0+cu128, а не новейший 2.15.0 | 2.15 выходит только с CUDA 13 (cu132/cu134); CTranslate2 4.9.0 под Windows собран с CUDA 12.8 + cuDNN 9 и требует `cublas64_12.dll`. Сборка cu128 поддерживает sm_120 и несёт ровно эти DLL |
| 2026-11-11 | 0.2 | DLL CUDA 12/cuDNN 9 для faster-whisper берутся из `torch\lib` (`trainer/gpu_env.py`: `add_dll_directory` + `PATH`), отдельный CUDA Toolkit не ставится | Работает без прав администратора; проверено запуском на RTX 5060 |
| 2026-11-11 | 0.2 | espeak-ng не ставится в систему: используется библиотека 1.52.0 из пакета `espeakng-loader` (зависимость misaki) | Не нужны права администратора; пункт HUMAN_TASKS «подтвердить установку espeak-ng» не потребовался |
| 2026-11-11 | 0.2 | Модели закреплены по коммитам HF (`trainer/model_registry.py`) и грузятся через `snapshot_download`; в работе — только `local_files_only` | Воспроизводимость и офлайн-режим; модель `turbo` = `mobiuslabsgmbh/faster-whisper-large-v3-turbo` |
| 2026-11-11 | 0.2 | Kokoro и голоса грузятся с `torch.load(weights_only=True)` (так в коде kokoro 0.9.4) | Требование безопасности к весам в формате pickle |
| 2026-11-11 | 0.2 | spaCy-модель `en-core-web-sm==3.8.0` закреплена в lock-файле | Иначе misaki скачивает её во время работы приложения |
| 2026-11-11 | 0.2 | Ресемплинг — `soxr` (HQ) | Лёгкая зависимость, нужна для 24/48 кГц → 16 кГц |
