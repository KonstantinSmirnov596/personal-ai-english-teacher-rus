## Фонемы (пункт 0.7)

Словарь `wav2vec2-lv-60-espeak-cv-ft` — 392 символа. Все символы espeak-ng `en-us` для 20 слов-проб есть в словаре, в том числе составные (`ɑːɹ`, `ɔːɹ`, `ɛɹ`, `ɪɹ`, `ʊɹ`, `oʊ`, `aɪ`, `aʊ`, `eɪ`, `dʒ`, `tʃ`, `ɚ`, `ɜː`, `ᵻ`, `ɾ`). Подробности: `docs/reports/data/phonemes_stage0.json`.

Расхождения каталога `l1_ru_catalog.json` (обычная МФА) с выводом espeak-ng `en-us`, которые этап 3 должен учесть:

| Каталог (МФА) | espeak-ng en-us и словарь модели | Пример |
| --- | --- | --- |
| `ɝ` | `ɜː` (ударная), `ɚ` (безударная); отдельного `ɹ` после неё нет | bird → `b ɜː d`, father → `f ɑː ð ɚ` |
| `ɑ` | `ɑː` | cot → `k ɑː t` |
| `ɔ` | `ɔː` | caught → `k ɔː t`, water → `w ɔː ɾ ɚ` |
| `ə` | `ə`, `ɐ`, `ᵻ` | about → `ɐ b aʊ t`, roses → `ɹ oʊ z ᵻ z` |
| гласная + `ɹ` | один символ: `ɑːɹ`, `ɔːɹ`, `ɛɹ`, `ɪɹ`, `ʊɹ` | car → `k ɑːɹ`, more → `m ɔːɹ` |
| `i` в конце слова | `i` (не `iː`) | very → `v ɛ ɹ i`, happy → `h æ p i` |
| `t` между гласными | `ɾ` | better → `b ɛ ɾ ɚ` |
| `ŋk`, `ŋɡ` в поле `heard` | последовательность двух символов | sing → `s ɪ ŋ` |

Свободное распознавание фонем на отдельных синтезированных словах (3 голоса × 20 слов) совпало с эталоном espeak в 34 из 60 случаев. Типичные отличия: `ɔː → ɑː` (3 раза; это допуск cot/caught), `ɑːɹ → ɑː`, лишние символы в конце слова (`z`, `ə`, `a`) и оглушение/озвончение конечных `p`/`b`. Вывод для этапа 3: оценку строить на принудительном выравнивании и GOP, а свободное распознавание использовать только для диагноза «что прозвучало» и только внутри отрезка фонемы.

## Решения и отклонения

- torch 2.11.0+cu128 вместо новейшего 2.15.0: в 2.15 нет сборок CUDA 12, а CTranslate2 4.9.0 под Windows требует `cublas64_12.dll`. Сборка cu128 поддерживает sm_120 и несёт нужные DLL cuBLAS 12 и cuDNN 9.
- CUDA Toolkit и cuDNN отдельно не ставятся: `trainer/gpu_env.py` открывает `torch\lib` загрузчику Windows.
- espeak-ng берётся из пакета `espeakng-loader`; пункт HUMAN_TASKS о правах администратора не понадобился.
- `beam_size=1` для разговора: на 10 с речи 0,31 с против 0,37 с у `beam_size=5`, в петле TTS → STT ошибок нет ни там, ни там. Значение можно поднять в настройках, если на живой речи появятся ошибки.
- Уверенность слова (пункт 0.5): faster-whisper отдаёт `Word.probability` — среднюю вероятность токенов слова. Замена не нужна.
- Порт окна будет фиксированным, а не случайным при каждом запуске (пункт 1.1): разрешение микрофона Edge хранит для origin с портом, и при случайном порте запрос появлялся бы при каждом запуске. Защиту (токен, cookie, `Host`, `Origin`) это не ослабляет.
- wav2vec2 существует только в формате `pytorch_model.bin`; transformers 5.22 загружает его с `weights_only=True`.

## Не получилось

- Живой запрос к DeepSeek (пункт 0.4) не выполнялся: ключа нет. Документация разобрана в `docs/reports/deepseek.md`, живая проверка перенесена в набор `live` этапа 1.
- Загрузка Kokoro занимает 11,5 с: основное время уходит на импорт spaCy и misaki. Цель запуска 20 с достижима, если ядро загружает модели параллельно с открытием окна; это проверит этап 4.
