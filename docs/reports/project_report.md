# Голосовой тренажёр американского английского: итоговый отчёт

Отчёт описывает, что в итоге построено, как это устроено и чем подтверждено. Подробности по этапам — в `docs/reports/stage0.md` … `stage3.md` и `final.md`, решения с причинами — в `docs/PROGRESS.md`.

## Кратко

- Персональное приложение для Windows: голосовой разговор с ИИ-собеседником на американском английском, правки на русском, оценка произношения по звукам.
- Распознавание, синтез речи и оценка произношения работают локально на видеокарте RTX 5060 Laptop. Наружу уходит только текст диалога, и только к адресу выбранного LLM API.
- Реализованы все обязательные пункты плана, этапы 0–4. Каждый этап принят скриптом `scripts/check_stage.ps1 <N>` с кодом 0. Необязательный пункт 2.8 (Smart Turn) не делался.
- Владелец проверил приложение вручную и подтвердил, что оно работает.
- Объём:
  - около 11 тысяч строк кода ядра и окна;
  - около 4,5 тысячи строк тестов: 108 быстрых, 25 с видеокартой, 11 сквозных через Edge, 2 с живым провайдером.

## Что умеет приложение

### Разговор

- Шесть сценариев:
  - свободный разговор;
  - собеседование на backend-разработчика;
  - собеседование на разработчика ERP и ECM;
  - ежедневный стендап;
  - созвон с заказчиком об автоматизации документооборота;
  - small talk с коллегой.
- Уровень собеседника: A2, B1 (по умолчанию), B2 или C1.
- Два режима реплик:
  - **Ручной:** Пробел начинает и заканчивает реплику, Esc отменяет её.
  - **Авто:** конец реплики определяет детектор речи Silero VAD в окне. Допустимая пауза настраивается от 1,0 до 3,0 с.
- Собеседник отвечает голосом: ответ озвучивается по предложениям, первое звучит, пока следующие ещё генерируются.
- Перебивание:
  - Пробелом — всегда;
  - голосом — с флажком «Я в наушниках».

  После перебивания поток LLM закрывается, остаток ответа не звучит, а правки к вашей реплике всё равно приходят.
- Собеседник вслух не исправляет. Он может естественно повторить верную форму в ответе (переключатель recast).
- В ленте видна ваша реплика в том виде, в каком её услышало распознавание.

### Правки на русском

- Готовит их отдельный запрос «корректор». Ответ — JSON, его проверяет схема pydantic.
- До трёх правок на реплику. У каждой правки:
  - дословный фрагмент реплики;
  - исправление;
  - тип ошибки;
  - пояснение на русском до 20 слов;
  - ключ повторяющейся ошибки.

  Отдельно приходит вся фраза на естественном американском английском.
- Неуверенно распознанные слова (ниже порога уверенности faster-whisper) корректор не трогает: это может быть ошибка распознавания.
- Четыре режима показа: «Сразу», «По нажатию» (по умолчанию), «В конце», «Выкл.». В режиме «Выкл.» корректор не вызывается вовсе.
- Если фрагмент не найден в реплике дословно, правка остаётся в карточке без подчёркивания.

### Помощники, итоги, словарь

- **Помощники.** Озвучивается только английский текст:
  - «Подсказка» — два-три варианта ответа на английском;
  - «Перевод» — перевод реплики собеседника на русский, только текстом;
  - «Как сказать?» — английский вариант фразы, введённой по-русски;
  - «Повторить» и «Медленнее» (скорость 0,8) — реплика собеседника звучит заново.
- **Итоги сессии:**
  - один главный вывод с упражнением (ответ даётся голосом, распознаётся и проверяется);
  - остальные правки списком;
  - кнопка сохранения фраз собеседника в словарь.
- **Фокус практики.** Каждая правка размечается одним из 32 типов повторяющихся ошибок. Тип, встретившийся в трёх сессиях подряд, попадает в системный промпт следующих сессий: собеседник выводит разговор на эту конструкцию. После трёх сессий без этой ошибки тип закрывается. В промпт попадают не больше пяти типов, самые частые первыми.
- **Словарь** с интервальным повторением: интервалы 1, 3, 7, 14, 30, 60 дней, «Не помню» возвращает интервал к одному дню.
- **История:** прошлые разговоры с правками и итогами, экспорт.

### Произношение

- Экран «Чтение»: 26 фраз, подобранных под типичные трудности русскоговорящих.
  - Каждый звук фразы получает оценку «верно», «неточно» или «ошибка».
  - По клику на слово видно, что ожидалось и что прозвучало, совет и минимальная пара для тренировки.
  - Кнопка «Это было верно» снимает пометку и делает оценку этого звука мягче для вашего голоса.
- В разговоре подсвечиваются только явные ошибки:
  - только в словах, распознанных с уверенностью от 0,9;
  - только ошибки из каталога;
  - с порогом выше, чем в «Чтении».

  Оценка запускается после первого звука ответа и не задерживает разговор. Пометки в разговоре можно выключить в настройках.
- Каталог ошибок, типичных для русскоговорящих, — 20 записей. Среди них th → s/f/t/d/z, w ↔ v, ŋ → n, оглушение конечных звонких, ɪ ↔ iː, æ → ɛ, r-окрашенные гласные. Отдельно заданы 5 групп американских допусков: флэп, cot–caught, нераскрытое конечное /t/, слабые гласные, слабые формы служебных слов.

### Настройки

Пять разделов:

- «API-подключения»;
- «Звук и голос»: микрофон и динамики, шумоподавление, флажок «Я в наушниках», 20 американских голосов Kokoro с прослушиванием, скорость 0,7–1,3, режим микрофона в «Чтении»;
- «Разговор»: режим реплик, допустимая пауза, уровень;
- «Правки»: режим показа правок, recast, пометки произношения в разговоре;
- «Данные»: срок хранения записей, экспорт, удаление всех данных. Ключи удаляются только с отдельным флажком.

## Как устроено

### Архитектура

```
Edge --app (окно, без адресной строки)          Ядро: один процесс Python 3.12
  HTML + CSS + ES-модули, без сборки   <------>  FastAPI + uvicorn на 127.0.0.1:47613-47622
  AudioWorklet: захват 16 кГц                    |- GpuQueue: один поток для работы с видеокартой
  Silero VAD (onnxruntime-web, WASM)             |- faster-whisper turbo (float16, CUDA)
  Web Audio: воспроизведение и волна             |- Kokoro-82M (lang_code='a')
                                                 |- wav2vec2 lv-60 espeak + espeak-ng en-us
                                                 |- SQLite (%LOCALAPPDATA%\EnglishTrainer)
                                                 '- httpx --HTTPS--> OpenAI-совместимый LLM API
```

- Окно — статический фронтенд, который отдаёт само ядро. Внешних шрифтов, скриптов и CDN нет: шрифты Inter и JetBrains Mono, детектор речи и WASM-сборка onnxruntime скачиваются при установке с проверкой sha512 и лежат в `web/`.
- Ядро и окно общаются по WebSocket (реплики, поток ответа, правки, состояния) и HTTP (настройки, история, словарь, чтение). Контракт — `docs/protocol.md`, все сообщения описаны pydantic-моделями.
- Порт фиксированный: первый свободный из 47613–47622. Edge хранит разрешение микрофона для пары «адрес + порт», и при случайном порте спрашивал бы его при каждом запуске.

### Поток одной реплики

1. Окно записывает речь (16 кГц моно) и по концу реплики отправляет её ядру.
2. faster-whisper распознаёт текст с уверенностью по словам: `beam_size=1`, VAD-фильтр.
3. Пустая реплика (тишина, шум) отбрасывается без запроса к LLM.
4. Параллельно стартуют два запроса:
   - **собеседник** — потоковый ответ (SSE);
   - **корректор** — JSON с правками.
5. Поток собеседника режется на предложения: правила учитывают сокращения, числа и инициалы. Каждое предложение синтезирует Kokoro и сразу отправляет в окно.
6. Перед синтезом текст проверяется на кириллицу; русский текст в синтез не попадает.
7. Окно проигрывает звук, переводит панель по состояниям `idle → listening → transcribing → thinking → speaking` и вставляет текст ответа только через `textContent`.
8. Оценка произношения слов реплики идёт фоном после первого звука ответа.
9. Длинная история сворачивается: когда сообщений больше 40, старейшие 20 заменяются кратким пересказом. Начало запроса к LLM побайтно одинаково между репликами, чтобы срабатывал кэш контекста провайдера.

### API-подключения

- Окно «API-подключения»: адрес, модель, дополнительные параметры запроса, кнопки «Сохранить» и «Проверить». Есть шаблон DeepSeek (`https://api.deepseek.com`, рассуждения выключены через `{"thinking": {"type": "disabled"}}`) и произвольный OpenAI-совместимый API.
- Ключ хранится только в Диспетчере учётных данных Windows (`keyring`). Окно получает лишь `••••` и 4 последних символа.
- Ошибки провайдера переводятся в понятные сообщения:
  - 401, 402, 403 — провайдер отклонил ключ (проверить ключ и баланс);
  - 429 — превышен лимит запросов;
  - 5xx, тайм-аут, обрыв потока — сбой ответа.

  Реплику можно повторить, в ленте есть кнопка «Переключить на…». Само приложение на другого провайдера не переключается: текст не должен уйти туда без согласия владельца.

### Оценка произношения

1. **Эталон.** Фраза целиком проходит через espeak-ng `en-us`, чтобы слабые формы и флэпы были такими же, как в данных обучения фонемной модели. Границы слов восстанавливаются динамическим программированием. У каждой позиции есть список допустимых американских вариантов.
2. **Акустика.** Выход wav2vec2 (392 символа) сводится к 52 классам звуков, включая акцентные: раскатистое «р» и /x/.
3. **Выравнивание.** Принудительное CTC-выравнивание (Витерби) даёт каждой фонеме отрезок записи.
4. **Оценка.** Для каждой фонемы на окне ±2 соседа сравнивается правдоподобие CTC эталона и эталона с заменой этой фонемы на конкурента: другой звук, пропуск или последовательность вроде ŋ+k. Все варианты считаются одним пакетом на видеокарте.
5. **Диагноз и совет.** Прозвучавший звук — самый правдоподобный конкурент. Пара «ожидалось → прозвучало» ищется в каталоге, оттуда берутся совет и минимальная пара.
6. **Пороги.** Для ошибки из каталога: «неточно» от 1,25, «ошибка» от 2,0. Для замены вне каталога: 3,5 и 7,0.

   «Это было верно» поднимает порог звука минимум на 1,0, максимум до 12.

Фонемная модель загружается при первом входе в «Чтение» или с первой реплики разговора и выгружается, если видеопамяти остаётся мало.

### Хранение данных

- Каталог `%LOCALAPPDATA%\EnglishTrainer`:
  - база SQLite с миграциями;
  - записи реплик;
  - модели;
  - журналы (ротация: 6 файлов по 2 МБ);
  - отдельный профиль Edge.
- В папке проекта данных нет.
- Записи старше срока хранения (по умолчанию 30 дней) удаляются при старте и каждые 6 часов.

### Безопасность

- Сервер слушает только `127.0.0.1`.
- Вход по одноразовому токену запуска. Токен обменивается на cookie `HttpOnly`, `SameSite=Strict`.
- Каждый запрос проверяется:
  - неверный `Host` — 421;
  - нет cookie — 401;
  - чужой `Origin` — 403. Для WebSocket и изменяющих запросов `Origin` обязателен.
- CORS не включён. CSP разрешает только свой адрес; `wasm-unsafe-eval` нужен для WebAssembly детектора речи, `eval` строк запрещён.
- Ключи вырезаются из журнала фильтром.
- Тест-маркер проверяет, что ключ встречается только в keyring и в запросах к LLM.
- Сетевой тест записывает все соединения процесса ядра за полный сценарий. Результат: 4 соединения, все к `127.0.0.1`, наружу — ни одного.
- Ответы LLM вставляются в DOM только как текст.

## Установка и запуск

- `scripts\setup.ps1` — одна команда на всё:
  - находит Python 3.12, ставит uv, создаёт `.venv`;
  - ставит зависимости по lock-файлу;
  - скачивает модели (около 3,2 ГБ), шрифты и детектор речи;
  - создаёт ярлык.

  Повторный запуск безопасен.
- Ярлык «Тренажёр» (в папке проекта, на рабочем столе, в меню «Пуск») запускает `pythonw -m trainer.launcher`, без консоли.
- Лаунчер:
  - держит один экземпляр через именованный мьютекс; повторный запуск выводит вперёд уже открытое окно;
  - открывает Edge в режиме приложения;
  - выставляет офлайн-режим библиотек моделей;
  - завершает ядро через 10 с после закрытия окна.
- Без видеокарты или моделей ядро не падает: окно объясняет причину простыми словами.
- `scripts\run.ps1` запускает то же самое из терминала, с сообщениями ядра.

## Как проверялось

Человек в автоматических тестах не участвует (`docs/testing.md`):

- **Петля TTS → STT.** Kokoro синтезирует фразы, faster-whisper их распознаёт; так проверяется качество обеих моделей.
- **Фейковый микрофон.** Edge запускается с флагами Chromium `--use-fake-device-for-media-stream` и `--use-file-for-fake-audio-capture=<wav>`. Сквозные тесты говорят с приложением заранее синтезированными репликами, в том числе с паузами и с «акцентом» (work с /v/, third с /s/, very как «wery»).
- **Мок LLM.** Локальный OpenAI-совместимый сервер с потоком SSE, задержками, ошибками 401/402/429/5xx и обрывами.
- **Без «чёрных ходов».** Тесты наблюдают окно только через `data-state` и `data-testid`.
- **Приёмка этапа.** `check_stage.ps1` повторяет `setup.ps1`, гоняет нужные наборы и проверяет наличие отчёта. На этапе 4 он ещё ставит приложение с нуля в чистую копию.

## Ключевые решения

- **Фиксированный порт** вместо случайного: разрешение микрофона в Edge привязано к порту.
- **Корректор — отдельный запрос** параллельно с ответом собеседника: ответ не ждёт правок, а правки не зависят от перебивания.
- **Синтез по предложениям**, а не по всему ответу: первый звук через 0,5–1 с после конца реплики.
- **GOP через отношение правдоподобий CTC на окне**, а не через среднюю вероятность по кадрам: выход CTC-модели состоит из коротких пиков, и усреднение на нём ненадёжно.
- **Минимальные пары тестировались во фразах-носителях** («I said X.», «Say X for me.»): отдельные слова Kokoro произносит нестабильно.
- **Smart Turn не делался.** Авто-режим с порогом паузы проходит критерии, а лишняя модель добавила бы обмен с ядром на каждую паузу.
- **Ярлык вне папки проекта** создан только по слову владельца: действия вне проекта требуют согласия.

## Известные ограничения

- **Произношение:**
  - пороги подобраны на синтезированных американских голосах и калибруются под владельца кнопкой «Это было верно»;
  - ненадёжны конечные /t/–/d/ (bad/bat — 50 %), /æ/ → /ɛ/ (54 %), /uː/ → /ʊ/ перед /l/ (8 %), ударный /ɜː/ без r-окраски;
  - раскатистое «р» и /h/ → /x/ на синтезе не проверить;
  - палатализация, придыхание, интонация и ударение не оцениваются;
  - пропуск звука даёт не выше «неточно».
- **Авто-режим** проверен на записи с паузой 1,2 с; на живой речи порог паузы подбирается в настройках.
- **Перебивание голосом** работает только в наушниках; на динамиках — Пробелом.
- **Интерфейс:** одна светлая тема, вёрстка проверялась в окне 1180×860.
- **Ключ и база:**
  - ключ API может прочитать любая программа под той же учётной записью Windows, поэтому ключ нужен отдельный, с лимитом расходов;
  - база не шифруется, данные на диске защищает шифрование устройства Windows.
- **Обновления** только через `setup.ps1`, автообновления нет.
