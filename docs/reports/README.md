# Отчёты

Сюда Claude Code пишет отчёты по этапам. Без отчёта этап не считается закрытым.

| Файл | Когда появляется |
| --- | --- |
| `stage0.md` | Конец этапа 0: версии, замеры, отклонения от целевого стека |
| `deepseek.md` | Пункт 0.4: параметры API по официальной документации, со ссылками |
| `stage1.md` … `stage3.md` | Конец соответствующего этапа |
| `final.md` | Конец этапа 4: показатели против целей, известные ограничения, что осталось владельцу |

## Состав отчёта этапа

1. **Итог одной строкой:** этап закрыт или нет, и что мешает.
2. **Показатели:** таблица «показатель, цель, замер, как измерено». Замер без запуска не записывается; если измерить не удалось, в ячейке стоит причина.
3. **Проверки:** какие наборы запускались, сколько тестов прошло, упало, пропущено; для пропущенных — причина.
4. **Решения и отклонения:** что сделано иначе, чем в `docs/design.md` и `docs/PLAN.md`, и почему.
5. **Не получилось:** что пробовал, что видел, что предлагаешь дальше.
6. **Нужно от владельца:** пункты из `docs/HUMAN_TASKS.md`, которые открылись на этом этапе.

Замеры записываются числами с единицами. Оценочные формулировки без числа в таблицу показателей не попадают.
