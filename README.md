# Personal AI English Teacher (RUS) for Desktop/Notebook with GPU

*Spoken American English practice for Russian speakers on Windows with an NVIDIA GPU. The interface and the documentation are in Russian. The version for Spanish and Brazilian Portuguese speakers: [Personal AI English Teacher (ES/PT)](https://github.com/KonstantinSmirnov596/personal-ai-english-teacher).*

**Тренажёр: голосовая практика американского английского для русскоговорящих.** Приложение для Windows: вы разговариваете голосом с ИИ-собеседником, получаете правки на русском и оценку произношения. Распознавание и синтез речи работают на вашем компьютере; наружу уходит только текст диалога в выбранный LLM API.

Проверено на одном компьютере: Windows 11, видеокарта RTX 5060 Laptop, 8 ГБ.

## Требования

| Что | Нужно |
| --- | --- |
| Видеокарта | NVIDIA GeForce RTX 20-й серии или новее, от 6 ГБ видеопамяти (проверено на 8 ГБ) |
| Драйвер NVIDIA | 572.61 или новее |
| Оперативная память | 16 ГБ (рекомендуется) |
| Диск | около 15 ГБ свободного места |
| Система | Windows 10 22H2 или Windows 11, Microsoft Edge (входит в Windows) |

Python ставить не нужно, права администратора не нужны. Установщик сам проверяет компьютер до того, как что-то скачать, и объясняет, чего не хватает.

## Установка

1. Скачайте `EnglishTeacher-RUS-<версия>.zip` со [страницы релизов](https://github.com/KonstantinSmirnov596/personal-ai-english-teacher-rus/releases). Рядом лежит `SHA256SUMS.txt` с контрольной суммой; сверить её можно в PowerShell: `Get-FileHash .\EnglishTeacher-RUS-<версия>.zip -Algorithm SHA256`.
2. Щёлкните архив правой кнопкой → «Свойства» → отметьте «Разблокировать» → «ОК». Так Windows не будет предупреждать о каждом скрипте.
3. Распакуйте архив в папку с коротким путём, например `C:\EnglishTeacherRUS`.
4. Дважды щёлкните `install.cmd`. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».

Установщик по шагам: проверяет видеокарту, драйвер, память и диск; ставит инструмент `uv` и Python 3.12 в папку тренажёра (в систему и в `PATH` ничего не добавляется); ставит пакеты Python по `uv.lock` (около 5 ГБ); скачивает речевые модели в `%LOCALAPPDATA%\EnglishTrainer\models` (около 3,2 ГБ), шрифты и детектор речи; создаёт ярлык «Тренажёр» в папке и по вашему ответу — на рабочем столе и в меню «Пуск»; запускает тренажёр. В первый раз это занимает 20–60 минут в зависимости от интернета. Все загрузки закреплены по версиям и проверяются по контрольным суммам.

Интернет нужен только при установке. Если связь оборвалась, снова запустите `install.cmd`: он продолжит с того места, где остановился.

## Запуск

Двойной щелчок по ярлыку «Тренажёр». Окно открывается сразу, модели загружаются ещё 10–15 секунд (в нижней панели написано «Загружаю модели…»). Повторный щелчок по ярлыку показывает уже открытое окно. После закрытия окна приложение завершается само через 10 секунд.

Запуск из терминала (видны сообщения ядра): `.\scripts\run.ps1`.

При первом запуске:

1. Нажмите значок настроек справа вверху → «API-подключения» → «Добавить подключение». Выберите шаблон «DeepSeek» (или укажите адрес и модель другого OpenAI-совместимого API), вставьте ключ, нажмите «Сохранить» и «Проверить». Заведите для приложения отдельный ключ с лимитом расходов.
2. Вернитесь в «Разговор», выберите сценарий, нажмите «Начать разговор» и разрешите доступ к микрофону (один раз).

## Как пользоваться

| Экран | Что делает |
| --- | --- |
| Разговор | Пробел начинает и заканчивает реплику, Esc отменяет. Во время ответа Пробел перебивает собеседника. Подчёркнутые слова — правки (клик открывает карточку), слова с оранжевой заливкой — явные ошибки произношения. Кнопки «Подсказка», «Как сказать?», под репликой собеседника — «Повторить», «Медленнее», «Перевод». «Завершить» показывает итоги с упражнением. |
| Чтение | Прочитайте фразу вслух: каждый звук получает оценку «верно», «неточно» или «ошибка», по клику на слово — что прозвучало и как исправить. Если пометка неверна, нажмите «Это было верно»: оценка этого звука станет мягче. |
| Словарь | Фразы собеседника, сохранённые из итогов, с повторением через растущие интервалы. |
| История | Прошлые разговоры с правками и итогами, экспорт. |
| Настройки | Подключения, микрофон и голос, уровень и режим реплик («Ручной» или «Авто» с допустимой паузой), показ правок, срок хранения записей, экспорт и удаление данных. |

Первые 10 фраз в «Чтении» лучше потратить на калибровку: пороги подобраны на синтезированных голосах и подстраиваются под ваш голос кнопкой «Это было верно».

## Где что лежит

| Что | Где |
| --- | --- |
| База, записи реплик, журналы, профиль окна, модели | `%LOCALAPPDATA%\EnglishTrainer` |
| Ключи API | Диспетчер учётных данных Windows, записи `EnglishTrainer`; в базе и файлах ключей нет |
| Журнал | `%LOCALAPPDATA%\EnglishTrainer\logs\trainer.log` (до шести файлов по 2 МБ) |
| Программа, Python и пакеты | Папка тренажёра (`.venv`, `.tools`); ваших данных в ней нет |

Наружу приложение обращается только к адресу активного подключения LLM. Туда уходит текст ваших реплик, ответы собеседника и системные промпты. Звук не уходит никуда.

## Обновление

Закройте тренажёр, распакуйте новую версию поверх старой папки (или в новую) и снова запустите `install.cmd`. Скачается только то, что изменилось. Разговоры, настройки, ключи и модели сохраняются; база обновляется сама при следующем запуске.

## Резервная копия

Закройте приложение и скопируйте папку `%LOCALAPPDATA%\EnglishTrainer` без подпапок `models` (скачивается заново) и `edge-profile`. Для восстановления верните файлы на место. Ключи API в копию не входят: на другом компьютере их нужно ввести заново. Отдельные разговоры и словарь можно выгрузить в «Настройки → Данные → Экспорт».

## Удаление

Дважды щёлкните `uninstall.cmd` в папке тренажёра. Он закрывает тренажёр, удаляет окружение Python, скачанные инструменты, шрифты и ярлыки. Отдельно спрашивает, удалить ли ваши данные (`%LOCALAPPDATA%\EnglishTrainer`: разговоры, записи, настройки, модели) и ключи API из Диспетчера учётных данных Windows; без вашего «да» они остаются. Саму папку тренажёра после этого можно удалить.

## Если что-то не так

| Сообщение или симптом | Что делать |
| --- | --- |
| «Не найдена видеокарта NVIDIA…» | Обновите драйвер NVIDIA, проверьте `nvidia-smi` в терминале, перезапустите приложение |
| Установщик остановился | Прочитайте сообщение над строкой «Установка остановлена», устраните причину и снова запустите `install.cmd`: он продолжит с того же места |
| Установщик просит перенести папку | В пути есть буквы, которые не читает компонент произношения, или путь слишком длинный: распакуйте архив в `C:\EnglishTeacherRUS` |
| «Модели не найдены…» | Запустите `install.cmd` при подключённом интернете |
| «Нет API-подключения» | Добавьте подключение и нажмите «Проверить» |
| «Провайдер отклонил ключ…» | Проверьте ключ и баланс у провайдера; в ленте есть кнопка «Переключить на…» другое подключение |
| «Сигнала нет — проверьте микрофон» | Выберите микрофон в «Настройки → Звук и голос»; проверьте, что Windows не отключила доступ к микрофону |
| Авто-режим обрывает реплики | Увеличьте допустимую паузу в «Настройки → Разговор» или вернитесь в ручной режим |
| Окно не открылось | Запустите `.\scripts\run.ps1` и посмотрите сообщения; журнал — в `logs\trainer.log` |

## Для разработки

Нужен клон репозитория (в архиве релиза нет тестов).

- `scripts\setup.ps1 -Dev` — установка с инструментами тестов (pytest, ruff, Playwright); `-Shortcuts no -NoLaunch` — без ярлыков и запуска.
- `scripts\test.ps1 fast|gpu|e2e|live|all` — наборы тестов; `live` обращается к вашему провайдеру и тратит деньги (не больше 80 запросов).
- `scripts\check_stage.ps1 <N>` — приёмка этапа: тесты, отчёты, установка с нуля.
- `scripts\make_release.py` — архив релиза `dist\EnglishTeacher-RUS-<версия>.zip` и `SHA256SUMS.txt`; `scripts\check_clean_install.py` — установка из этого архива в папки с кириллицей и пробелами на чистые `LOCALAPPDATA` и `TEMP`, запуск и удаление.
- Проект системы, план и отчёты по этапам с замерами — в `docs\`; известные ограничения — в `docs\reports\final.md`.
