# Голосовой тренажёр американского английского

Пакет для автономной разработки в Claude Code. Кода приложения здесь ещё нет: есть проект системы, план с критериями приёмки, спецификации и исходные данные. Claude Code строит приложение по ним и заменит этот файл инструкцией владельца на этапе 4.

## С чего начать

Откройте `KICKOFF.md`: там подготовка и стартовый промпт.

## Что в пакете

| Файл | Назначение |
| --- | --- |
| `KICKOFF.md` | Подготовка и промпты для запуска и продолжения работы |
| `CLAUDE.md` | Правила проекта; Claude Code читает их в каждой сессии |
| `.claude/settings.json` | Разрешения на команды: что выполняется без вопросов, что с подтверждением |
| `docs/design.md` | Проект системы: архитектура, решения, безопасность |
| `docs/PLAN.md` | Этапы 0–4, задачи, критерии приёмки, целевые показатели |
| `docs/PROGRESS.md` | Журнал хода работ; ведёт Claude Code |
| `docs/HUMAN_TASKS.md` | Что можете сделать только вы, и очередь вопросов к вам |
| `docs/protocol.md` | Контракт между окном и ядром: WebSocket и HTTP |
| `docs/testing.md` | Как приложение тестируется без человека |
| `docs/prompts/` | Промпты собеседника, корректора, итогов и помощников |
| `docs/data/` | Сценарии, ключи ошибок, каталог ошибок произношения, фразы для чтения, набор для проверки корректора |
| `docs/ui/` | Статичные макеты четырёх экранов и токены оформления |
| `docs/reports/` | Сюда Claude Code пишет отчёты по этапам с замерами |

## Как устроена автономность

- Каждый этап заканчивается командой приёмки `scripts/check_stage.ps1 <N>`. Пока она не прошла, этап не закрыт.
- Тесты не требуют человека: речь для них синтезирует Kokoro, микрофон в сквозных тестах заменяет WAV-файл, LLM заменяет локальный мок-сервер.
- Состояние работы хранится в `docs/PROGRESS.md`, поэтому её можно продолжить в новой сессии одной фразой.
- Вопросы к вам копятся в `docs/HUMAN_TASKS.md` и задаются пачкой в конце этапа.

## Что остаётся за вами

Ввести ключ API в окне приложения, один раз разрешить микрофон, оценить на слух голос и задержку, откалибровать оценку произношения на своём голосе. Полный список — в `docs/HUMAN_TASKS.md`.
